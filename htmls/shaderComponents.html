Parameters

Distinct input variables (defined in script or editor view)
Editor values should be added in shader header
All variable input values must be declared in CBUFFER
Parameters are conventionally prefaced with an '_'

Data Types

  • Float/Half – Floating decimal value (32 bit / 16 bit)
  • Int – Integer value; non-negative whole number (32 bit)
  • Color – 4D Vector representing a color in RGBA decimal format (128 bit)
  • 2D Texture – Image that can be sampled within shader

Functions

Vertex

Runs per each vertex
Transforms vertex position to clip space
Allows for vertex displace and manipulation

Fragment

Runs per each pixel
Calculates the final pixel color
Function for calculating all lighting and texture sampling
