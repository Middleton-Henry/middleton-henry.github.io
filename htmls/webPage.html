Overview

This webpage is specfically created for writing in ShaderLab and hlsl which is the system used by Unity URP

What is a shader?

A script that defines parameters and code that can be dispatched to and run by the GPU
Shader scripts are designed to run many independent low level functions simultaneously

What is a material?

An object instance of a shader that holds independent parameter values and can be assigned to in game objects
shader scripts themselves cannot be directly assigned to objects but can only be used to create material instances)
