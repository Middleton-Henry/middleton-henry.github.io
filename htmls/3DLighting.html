Physically Based Rendering (PBR)

PBR is the current standard for how to calculate 3-D lighting and how to render 3-D scenes
This system is on creating an accurate reflection for how actually look without having to rely on expensive algorithms/systems like raytracing

Standard Surface properties:

  • Albedo (texture) – The color of a surface
  • Normal Map (texture) – The direction of a surface (used to create bumps and other sub vertex details)
  • Roughness (greyscale texture) – How shiny or diffuse a surface is
  • Smoothness (float) – The strength of the Roughness texture

Additional Surface Properties:

  • Metallic (texture) – Alternative system to roughness that only applies to glossy calculations and ignores diffusion
  • Ambient Occlusion (greyscale texture) – Used to mark crevices of a surface to make them darker (typically baked into the Abedo)
  • Height Map (greyscale texture) – Greyscale image that marks the height of a pixel from its surface (typically baked into the Normal Map)

For more information on textures and other parameters visit Shader Components

Standard Lighting Formulae

NdotL – How closely a pixel’s normal faces towards a light (from 0 to 1)


                float NdotL = saturate(dot(normalWS, mainLight.direction));

Lambertian Diffusion

Soft surface lighting 


                half3 diffuse = NdotL * mainLight.shadowAttenuation * albedo * mainLight.color;

Phong Specular

Bright glossy lighting 


                floats viewDir = GetWorldSpaceNormalizeViewDir(positionws);
                floats reflectDir = reflect(-mainLight.direction, normalws);
                float spec = pow(max(dot (viewDir, reflectDir), 0.0), _Shininess);
                half3 specular = spec * mainLight.color * _SpecularStrength;

{
    Name "ShadowCaster"
    Tags
    {
        "LightMode" = "ShadowCaster"
    }

    ZWrite On
    ZTest LEqual
